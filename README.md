# CIS310 — Data Analysis with Python

Coursework and practice from CIS310 at Colorado State University: about a
year of hands-on data analysis in Python, working through data cleaning,
exploration, and visualization on real datasets.

## Overview

This repository collects the notebooks, scripts, and notes I built while
learning to work with data in Python — from loading and cleaning messy
datasets to exploratory analysis and turning results into clear
visualizations. It reflects consistent, ongoing practice rather than a
single project.

## What's inside

- Jupyter notebooks working through data analysis concepts and exercises
- Data cleaning and transformation with pandas
- Exploratory data analysis and summary statistics
- Data visualization with matplotlib

## Tools & libraries

- **Python** — pandas, NumPy, matplotlib
- **Jupyter Notebook**
- **Git / GitHub**

## Skills demonstrated

- Loading, cleaning, and reshaping data from multiple formats
- Exploratory analysis to surface patterns and summarize datasets
- Communicating findings through clear, readable visualizations
- Writing organized, reproducible analysis code
